## Audio needed
- Original loopable Dockside combat music.
- Waterfront ambience.
- Punch, kick, block, throw, hit, knockdown and special effects.
- Boss intro and stage-clear stingers.

## Import checklist for each sprite atlas
- Transparent background.
- Consistent frame cell dimensions.
- Consistent feet baseline and character scale.
- Explicit facing direction.
- No labels, borders or HUD baked into gameplay frames.
- Confirm frame order against an animation manifest.
- Test frame alignment in the selected OpenBOR build.
