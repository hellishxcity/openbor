# Streets of Violence

An original OpenBOR side-scrolling beat-'em-up project. This project is separate from NinaStorm: The Bloodstorm and separate from any reference game's content.

## Project identity
- **Title:** Streets of Violence
- **Engine target:** OpenBOR
- **Platform target:** Android first, landscape orientation
- **Genre:** 2D side-scrolling beat-'em-up
- **Opening district:** Dockside District
- **First milestone:** Kanan and the full core roster playable; Dockside enemy waves; Brock bruiser encounter; Brick boss; original art, animation, music and sound.

## Core playable roster
- Kanan "Scorpion" Jaxon — fast martial artist; signature SCORPION STRIKE.
- Jaylen "Coldman" Jaxon — wrestler/street brawler; throws and heavy slams.
- Shai Hooks — kickboxer; fast technical strings.
- Jenni "Legs" Rows — taekwondo specialist; undercover police officer.
- Nona "Beauty" Silks — MMA/grappler; takedowns and throws.

## Secret playable unlockables
- **Romeo Wells** and **Mei Lin** are secret playable characters.
- Both unlock only after the player beats/completes the main game (Story Mode).
- Neither is part of the starting roster; their unlock is not tied to completing the bonus storyline.

## Original enemy direction
- Dockside Grunts — basic gang fighters.
- Brock — heavy bruiser; slow wind-up, powerful attacks, punishable recovery.
- Street Vipers — agile pressure fighters.
- Iron Guards — defensive enforcers.
- Brick — recurring boss.

## Original-content rule
Use OpenBOR engine capabilities, public documentation, and lawful development tools. The uploaded SOR2X PAK is a reference for understanding archive/layout conventions only. Do not copy its protected characters, sprites, backgrounds, music, sound effects, scripts, stages, names, or other expressive content. All Streets of Violence content must be original or properly licensed.

## Build status
This repository folder currently contains project documentation and design scaffolding, not a compiled game or Android APK. Do not describe the project as playable until it has been built and tested in OpenBOR on the target device.

## Development sequence
1. Lock character roster, combat roles, and stage-one encounter design.
2. Create original sprite atlases and convert them into consistent transparent animation frames.
3. Implement OpenBOR character definitions and animation scripts.
4. Build Dockside stage and enemy wave progression.
5. Add Brick boss fight and HUD.
6. Add original audio.
7. Test in OpenBOR, then validate Android packaging and touch controls.
